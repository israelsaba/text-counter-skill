# Contributing

Contributions are welcome through pull requests.

Before opening a PR:

- Explain the problem and the intended user or agent benefit.
- Keep the skill focused and preserve the portable `SKILL.md` entry point.
- Add or update tests when counting behavior changes.
- Check Markdown formatting, links, frontmatter, and cross-platform guidance.
- Describe what you reviewed or tested in the PR body.

Small documentation fixes are welcome. For larger changes, open an issue first so the scope can be discussed before implementation.

## Issues

Use issues for reproducible bugs, unclear guidance, installation problems, compatibility reports, and focused proposals. Include the skill version or commit, agent and version, operating system, expected behavior, actual behavior, and a minimal example when relevant.

Please do not use public issues for security vulnerabilities or private data. Follow [SECURITY.md](SECURITY.md).
